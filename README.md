# 🛡️ PlayerReportHelper Plugin

> Утилита и плагин для серверов Minecraft (Spigot / Paper API), созданный для автоматизации работы администрации, удобной подачи и обработки жалоб (репортов) на игроков.

![Java](https://img.shields.io/badge/Java-17%2B-orange?style=for-the-badge&logo=openjdk)
![PaperMC](https://img.shields.io/badge/PaperMC-API-blue?style=for-the-badge)

---

## 🌟 Основные возможности

* 📢 **Удобная система репортов:** Игроки могут быстро отправить жалобу на нарушителя через простые команды или GUI-меню.
* 👨‍💻 **Панель модератора:** Уведомления администрации в реальном времени о поступающих репортах с подробной информацией.
* 📋 **Очередь жалоб (Report Queue):** Сохранение и структурирование всех активных жалоб, чтобы ни одно обращение не потерялось.
* ⚡ **Быстрые действия:** Возможность мгновенного телепорта к подозреваемому, открытия инвентаря или применения санкций прямо из меню обработки.
* 🔔 **Звуковые и визуальные оповещения:** Настраиваемые звуковые эффекты и Actionbar/Title уведомления для модераторов.

---

## 🛠 Технологический стек

* **Language:** Java 17
* **API:** Paper / Spigot API
* **GUI Engine:** Custom Inventory Holder / Smart Ingame UI
* **Build Tool:** Maven
